# Everything Everything Groceries Platter

A free, mobile-friendly starter website with:
- Product catalogue
- Demo prices from GH₵50–GH₵120
- Shopping cart
- Custom platter builder
- WhatsApp checkout
- Responsive design
- Your original flyer included in `flier.jpeg`

## Change prices
Open `script.js` and edit the `price` values in the `products` list.

## Change WhatsApp number
Search for `233547026348` in `index.html` and `script.js` and replace it with the business WhatsApp number.

## Put it online for free
Create a GitHub repository, upload these files, then enable GitHub Pages in the repository's Settings → Pages. Your site can use a free `github.io` address.
